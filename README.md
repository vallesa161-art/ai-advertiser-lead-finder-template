# Ai-Advertiser AI Lead Finder Template

Day 2 of the Ai-Advertiser 3-Day Workshop (Starter track) — a working AI Lead
Finder built on Base44 core integrations only.

Type a niche + city and the AI web-searches real local businesses into your
Prospect table (name, phone, website, address). Per-lead AI Outreach Writer
drafts a personalized first-touch message. Niche filter chips, Qualified
tracking, CSV export.

**Zero setup:** no backend functions, no secrets, no API keys, no external
accounts. Runs on InvokeLLM (a Base44 core integration available on every
plan).

Clone it into your own Base44 account with one Plan-mode prompt:

```
Build my app from this GitHub repo:
https://github.com/wetzlr/ai-advertiser-lead-finder-template
```
